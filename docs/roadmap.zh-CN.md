# 路线图（中文）

## Phase 0 — 环境验证

目标：验证 OpenRA-RL 与 ra2yrcpp 两条路线的可行性并确认工程边界。

### 轨道 B — ra2yrcpp 原版注入

- 已验证可通过原版游戏进程读取结构化状态
- 已确认命令执行链路可用
- 已确认完整 episode 可以从开始到结束正常关闭

### 轨道 A — OpenRA-RL

- 已确认环境启动、reset、step、观测和奖励流通
- 已验证完整 episode 和 surrender / done 处理
- 适合做快速开发和无头训练

## Phase 1 — 最小 Gym 环境

目标：构建可运行的 Gymnasium 环境，支持随机 Agent 连续跑完整 episode。

待完成项：

- 实现 RA2Env 核心类
- 实现最小观测空间
- 实现最小动作空间
- 实现基础奖励函数
- 完成恢复逻辑与自动重启
- 随机 Agent 压力测试

验收标准：

- 随机 Agent 连续跑 100 局不崩溃

## Phase 2 — 基线 Agent

目标：实现 PPO 基线并在固定地图上与简单 AI 进行对战验证。

待完成：

- SB3 / PPO 集成
- 训练配置与超参数定义
- TensorBoard 监控
- 奖励 shaping
- 评估脚本

验收标准：

- 在固定地图上 PPO Agent 的胜率超过 50%

## Phase 3 — 观测与动作增强

目标：支持更丰富的策略学习和更真实的 RTS 构建逻辑。

待完成：

- 空间特征图
- 实体列表与 Transformer Encoder
- 扩展动作空间
- Action Masking
- 更高难度对手

## Phase 4 — 基础设施加固

目标：支持规模化训练和更稳定的工程部署。

待完成：

- Docker 容器化
- 并行环境
- Checkpoint 管理
- 崩溃恢复增强

## Phase 5 — 高阶架构

目标：探索更复杂的 RL 体系架构。

待完成：

- 分层 Agent
- 自我博弈训练
- 训练环境到对战平台的迁移

## 总结

当前项目已经完成了几乎最关键的前置条件：

- 真实 RTS 环境入口已验证
- 框架结构已明确
- 公开项目结构已整理
- 下一步的核心任务转向最小 Gym 环境的实现

这意味着项目已经从“可行性研究”进入“工程落地”阶段。
