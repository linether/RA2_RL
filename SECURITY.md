# Security Policy

## Supported versions

This project is currently under active development, and the repository is treated as a research and engineering workspace rather than a long-term stable production release.

Security issues will be handled on a best-effort basis as the project evolves.

## Reporting a vulnerability

Please do not report security issues publicly in the issue tracker.

Instead, contact the project maintainer privately using the repository owner’s GitHub contact information or via a private channel agreed by the maintainer.

Please include:

- a clear description of the issue
- reproduction steps if available
- affected files or components
- severity assessment if known
- any suggested mitigation

## Response expectations

We will make a reasonable effort to:

- acknowledge the report
- assess the impact
- determine whether a fix is needed
- coordinate a fix and disclosure timeline if appropriate

Because this project involves local game-process integration and research tooling, some issues may require a more targeted or platform-specific fix rather than a generic security patch.

## Safe handling guidelines

Please avoid exposing or sharing:

- private tokens or credentials
- local machine-specific paths or secrets
- user-generated game files that may contain personal data

## Disclosure

We prefer responsible disclosure and will coordinate with the reporter on appropriate public communication when necessary.
